# Resume site

A GitHub Pages-ready resume built with Jekyll and the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) remote theme.

## Local preview

Use Ruby 3.1.7 (the version pinned in `.ruby-version`) and Bundler, then run:

```sh
bundle install
bundle exec jekyll serve --livereload
```

Open <http://localhost:4000> in a browser.

The resume content is in [`index.md`](index.md), and site-wide settings and contact links are in [`_config.yml`](_config.yml). The current copy is intentionally placeholder content until the resume context is provided.
